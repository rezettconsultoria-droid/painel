## 🚀 Como publicar — 3 passos

### Passo 1 — Criar repositório no GitHub
1. Acesse [github.com](https://github.com) e faça login (ou crie conta gratuita)
2. Clique em **New repository** (botão verde)
3. Nome sugerido: `jp-painel` (tudo minúsculo, sem espaços)
4. Marque **Public** (obrigatório para GitHub Pages gratuito)
5. Clique em **Create repository**

### Passo 2 — Subir o arquivo
1. Na página do repositório recém-criado, clique em **uploading an existing file**
2. Arraste o arquivo `index.html` e o `README.md` para a área de upload
3. Clique em **Commit changes**

### Passo 3 — Ativar o GitHub Pages
1. No repositório, clique em **Settings** (engrenagem, menu superior)
2. No menu lateral esquerdo, clique em **Pages**
3. Em **Source**, selecione **Deploy from a branch**
4. Em **Branch**, selecione **main** e pasta **/ (root)**
5. Clique em **Save**
6. Aguarde 1-2 minutos e atualize a página

✅ **Sua URL estará disponível em:**
```
https://SEU_USUARIO.github.io/jp-painel
```

## 🔗 Como compartilhar

- **WhatsApp / Email:** cole a URL diretamente — abre no navegador do celular
- **Google Drive:** salve a URL como atalho (botão direito → Novo → Mais → Google Sites ou Atalho)
- **Reuniões:** abra a URL no Chrome, pressione **F** para tela cheia ou use a função nativa do navegador (F11)
- **Atalhos de teclado:** teclas **1 a 5** navegam entre as abas, **F** ativa tela cheia

---

## 🔄 Como atualizar o painel

1. Edite o arquivo `index.html` localmente
2. No repositório GitHub, clique no arquivo `index.html`
3. Clique no ícone de lápis (✏️ Edit)
4. Cole o novo conteúdo
5. Clique em **Commit changes**
6. A URL atualiza automaticamente em menos de 1 minuto

---

## 🔒 Segurança

O repositório **Public** significa que qualquer pessoa com a URL consegue ver o painel — mas não consegue editar. Se quiser restringir o acesso, o GitHub Pages com repositório **Private** requer plano pago. Alternativa gratuita: usar senha via Netlify (veja instruções em netlify.com).
