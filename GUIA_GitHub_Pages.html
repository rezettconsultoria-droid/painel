📤 Publicar o Painel no GitHub Pages

Guia completo em 5 passos — do zero ao link funcionando

⏱ Tempo estimado: 5–8 minutos  ·  Custo: Gratuito  ·  Requisito: Conta no GitHub
🌐
Ao final você terá uma URL pública permanente

Algo como https://jplocacoes.github.io/painel — abre em qualquer navegador, celular ou computador, sem instalar nada.

Parte 1 — Criar sua conta no GitHub (pule se já tem)
1
Acesse github.com e crie uma conta gratuita
Abra github.com no navegador. Clique em Sign up (canto superior direito).

Preencha:
  • Username — este nome aparecerá na sua URL. Ex: jplocacoes
  • Email — use um email que você acessa
  • Password — senha segura
💡 Escolha o username com cuidado — ele fará parte da URL do painel. Sugestão: jplocacoes ou jpazevedo
Parte 2 — Criar o repositório
2
Criar um novo repositório
Após fazer login, clique no ícone + no canto superior direito → New repository.

Configure assim:
Repository name: painel
Description: Painel Financeiro JP Locações 2026
Visibility: ◉ Public  (obrigatório para GitHub Pages gratuito)
Initialize: ☐ Add a README file  (deixar desmarcado)

Create repository
⚠️ O repositório precisa ser Public. Repositórios privados só suportam GitHub Pages no plano pago.
Parte 3 — Fazer upload do arquivo
3
Subir o arquivo index.html
Na página do repositório recém-criado, você verá uma tela vazia com a mensagem "Get started by creating a new file or uploading an existing file".

Clique em uploading an existing file.

Arraste o arquivo index.html para a área de upload (ou clique em "choose your files").

Aguarde o upload terminar (barra de progresso) e então:
Commit changes
Message: Adiciona painel financeiro JP Locações

Commit changes
ℹ️ "Commit" é o nome que o GitHub dá para "salvar". Clique e aguarde — leva menos de 5 segundos.
Parte 4 — Ativar o GitHub Pages
4
Ativar a publicação automática
No repositório, clique em Settings (ícone de engrenagem, menu superior).

No menu lateral esquerdo, role até encontrar Pages e clique.

Na seção Build and deployment, configure:
Source: Deploy from a branch
Branch: main  /  / (root)

Save
Clique em Save e aguarde 1–3 minutos.

✅ Quando estiver pronto, a própria página de Settings → Pages exibirá:
"Your site is live at https://SEU_USUARIO.github.io/painel"
Parte 5 — Acessar e compartilhar
5
Abrir o painel e compartilhar o link
Acesse a URL gerada pelo GitHub Pages:
🌐 https://SEU_USUARIO.github.io/painel
O painel abrirá diretamente no navegador — sem login, sem download, sem instalação.

Para compartilhar:
  • WhatsApp / Email: cole a URL — abre no celular automaticamente
  • Google Drive: crie um atalho → botão direito na pasta → Novo → Mais → Atalho → cole a URL
  • Reuniões: abra no Chrome e pressione F para tela cheia
  • Atalhos de teclado: teclas 1 a 8 navegam entre as abas
Como atualizar o painel no futuro
↺
Substituir o arquivo a cada fechamento mensal
Quando receber o arquivo index.html atualizado com os dados do mês:
  1. Acesse github.com/SEU_USUARIO/painel
  2. Clique no arquivo index.html
  3. Clique no ícone de lápis ✏️ (Edit this file)
  4. Selecione tudo (Ctrl+A) e cole o novo conteúdo
  5. Clique em Commit changes
A URL não muda. Em menos de 1 minuto o painel já está atualizado para todos.

💡 Alternativa mais rápida: na página do arquivo, clique nos três pontos ··· → Delete file, faça novo upload do arquivo atualizado. Resultado igual, um passo a menos.
Dúvidas frequentes
Qualquer pessoa pode ver o painel?
Sim — qualquer pessoa com o link consegue abrir. Mas sem o link, ninguém encontra o painel por busca (o Google não indexa páginas do GitHub Pages imediatamente). Se quiser restringir o acesso, a alternativa gratuita é o Netlify com senha — entre em contato com a reZett para configurar.
O que acontece se eu errar algum passo?
Nada é permanente no GitHub. Você pode apagar o repositório e começar de novo quantas vezes quiser. Vá em Settings → Danger Zone → Delete this repository.
Posso usar um domínio próprio (ex: painel.jplocacoes.com.br)?
Sim, o GitHub Pages suporta domínio personalizado gratuitamente. Você precisará ter acesso ao painel DNS do seu domínio. Em Settings → Pages → Custom domain, adicione o endereço desejado e siga as instruções de configuração do DNS. Tempo de propagação: 24–48h.
O painel funciona no celular?
Sim. O layout é responsivo — adapta para telas menores. Em celulares, as tabelas (DRE e Fluxo de Caixa) ficam com scroll horizontal para acomodar os 12 meses.
O GitHub é seguro? Meus dados ficam expostos?
Os dados financeiros estão embutidos no arquivo HTML. Quem tiver o link consegue ver — mas não consegue editar. Se os dados forem sensíveis e você quiser restringir o acesso, recomendamos hospedar no Netlify com autenticação por senha (gratuito no plano básico). Fale com a reZett para implementar.
Preciso pagar alguma coisa?
Não. GitHub gratuito + repositório público + GitHub Pages = R$ 0,00/mês. A única limitação é que o repositório precisa ser público. Para repositório privado com Pages, o GitHub cobra US$ 4/mês (GitHub Pro).
